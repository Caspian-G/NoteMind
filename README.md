# NoteMind

一个白灰极简风格的本地笔记 App，三个主功能模块：**备忘录**、**错题集**、**思维导图 + 笔记本**。
Kotlin + Jetpack Compose，纯本地存储，无网络、无账号、无广告。

---

## 一、三个模块

### 1. 备忘录 — 只记事情，不做层级

- 一条清单就是**一段纯文本**：没有标题、没有勾选、没有多级嵌套。
- 列表里**整段直接铺开展示**，内容再长也只是把卡片撑高，滚动即可读完，绝不做折叠或"展开查看更多"。
- 列表不显示条数、不显示时间，只有内容本身。
- 点右下角 `+` 新建，点卡片进入整页编辑。
- **删除**：向左拖动卡片，右侧露出红色「删除」键，点它才删。

### 2. 错题集 — 需要层级的地方才给层级

- 最外层是科目文件夹，**首次启动自动建好 `数学` `408` `英语` `政治`** 四个。
- 任意文件夹内既可以继续建**二级 / 三级子文件夹**，也可以直接建**错题文件**。
- 错题文件 = 题目/考点 + 照片 + 文字描述，**照片放在标题和正文之间**，缩略图放大到 118 dp，一眼就能确认拍了什么。
  - **拍照**：直接调用系统相机，照片存进应用私有目录 `filesDir/images/`。
    **不会进入系统「相册」App** —— 文件既不在共享存储里，也没有被 MediaStore 扫描过，
    相机 App 拿到的只是这一张图片的临时写权限。
  - **从相册选**：系统照片选择器，可多选；自动按 EXIF 方向矫正（原图仍留在相册里）。
- **看图**：点缩略图进全屏，**左右拖动切换**上一张/下一张，**双指捏合缩放**，双击放大或还原；
  没有"上一张 / 下一张"按钮，只在底部留一个页码。
- **删除**：向左拖动错题卡片，右侧露出红色「删除」键，点它才删。
- **移动**：文件夹和错题文件都支持「移动到…」，弹出完整目录树选择目标位置。
  - 文件夹不能移动到自己的子孙里（会被自动禁用）。
  - 删除文件夹会连同子文件夹和内部错题一起删除，删除前会提示会连带删掉多少内容。

### 3. 思维导图 + 笔记本 — 白底十字方格画布

- 整页**白底 + 灰色十字方格**，单指拖动、双指缩放，缩放范围 25%–300%，视图位置自动记住。
- 画布和顶栏都不放说明性文字，只在选中节点时显示一行「已选中「xxx」」。
- 右下角 `+` 创建**「笔记主索引」**：默认**圆角正方形**（190×190 dp）。
- **点一下**选中节点；**双击**选中并直接调出尺寸面板。
- **改大小 / 改长宽**三种方式：
  1. 选中后拖动**右边缘**只改宽、拖**下边缘**只改高、拖**右下角**同时改长宽；
  2. 双击节点或点工具栏「长宽」，输入宽/高 dp 值后「应用」；
  3. 面板里的「方形」一键恢复成正方形。
- **原地展开**：选中后点「展开」，节点会**在自身位置撑开成详细内容面板**（标题 + 分隔线 + 正文 + 图片），
  不会产生额外节点；展开后会顺手平移画布，保证内容不被工具栏挡住。点「收起」还原到展开前的尺寸。
- 「编辑内容」进入整页编辑：**索引名 → 拍照/相册（照片放在这两者之间，缩略图 118 dp）→ 正文**。
- 其它工具栏按钮：「拍照 / 相册」给选中节点直接加图、「子索引」生成一个带连线的子节点、「居中」把节点移到视野中央、「删除」连带删除其子节点。

#### 重新挂接父子关系

选中任意节点 → 工具栏「连接」，弹出「父索引」选择框：

- 顶部一行红字「断开与「xxx」的连接」，点一下就把当前父子关系解除，节点自己变成一棵独立的主索引；
- 下面是当前画布上所有索引的**树形列表**（按层级缩进），点谁就把谁设成父索引 —— **被点的那个是父，当前选中项是子**；
- **自己和自己的所有后代都会被禁选并标注「自身」/「子节点」**，从根上杜绝成环；
- 当前父索引带一个对勾，方便确认；
- 已经断开连接的节点，工具栏里的「断开」按钮会自动隐藏。

连接只改父子关系、**不会挪动任何节点**，连线会立刻重画；想让它们排整齐，接着点顶栏「整理」即可。

#### 自动整理索引树

顶栏「整理」按当前选中的节点决定整理范围：

- **选中了某个节点** → 只整理它所在的那一棵树；
- **什么都没选** → 画布上所有树各整理一遍。

排版规则（也是 `TreeLayoutTest` 覆盖的内容）：

- **根节点（主索引）保持原来的 x / y 完全不动**，其余节点围绕它生长；
- 子节点一律排在父节点右侧，一个父节点的所有子节点整体相对父节点**垂直居中**；
- 每棵子树独占一条垂直带，带宽取整棵子树实际需要的高度，所以**兄弟子树永远不会重叠**；
- 不属于这棵树的节点原样不动。

坐标是插值过去的（约 300 ms 缓出动画），不会一帧跳过去让人看不清节点跑哪了。

## 二、界面

- 主色只有白和灰：背景 `#FFFFFF`，面板 `#F2F2F2`，描边 `#E2E2E2`，文字 `#1F1F1F / #5A5A5A / #9A9A9A`。
- 固定浅色，不跟随系统深色模式，也不启用动态取色 —— 保证三个模块观感完全一致。
- 唯一的高亮色是删除操作使用的低饱和红 `#B4443C`。
- 底部只有三个图标入口，不带文字标签，没有抽屉、没有多余层级。

```
├── util/

└── ui/

    ├── theme/                      Color / Theme / Type（白灰配色、圆角、字体）
    ├── common/Components.kt        顶栏、确认框、输入框、图片条、全屏看图、目录树选择器、左滑删除容器
    ├── memo/MemoScreen.kt          模块一
    ├── mistake/MistakeScreen.kt    模块二
    └── mind/
        ├── MindMapScreen.kt        模块三
        └── TreeLayout.kt           索引树的自动排版算法（纯函数，可单测）

app/src/test/java/com/caspian/notemind/ui/mind/
└── TreeLayoutTest.kt               自动排版的 JVM 单测

app/src/androidTest/java/com/caspian/notemind/
└── ImageViewerZoomTest.kt          双指缩放的真机手势测试
```

`ui/common/Components.kt` 里有两个复用的交互件：

- `SwipeToDeleteBox` —— 左滑露出红色删除键的容器，备忘录和错题列表都用它。
- `ImagePreviewDialog` / `ZoomableImage` —— 全屏看图，左右翻页 + 捏合缩放。
  翻页用 `HorizontalPager`，缩放自写了一套指针处理：**未放大时的单指拖动完全不消费事件**，
  手势让给 Pager 翻页；一旦放大就锁住翻页，单指变成平移图片。

### 数据存储

个人笔记数据量很小，因此**没有引入数据库**，用一个 JSON 文件承载全部数据：

- 位置：`filesDir/notemind.json`（照片在 `filesDir/images/`，JSON 里只存文件名）。
- 内存里是一份 `StateFlow<AppData>`，界面直接订阅；写入走 150 ms 防抖后原子落盘（先写 `.tmp` 再 rename），
  所以拖动节点、缩放画布这种高频操作不会反复写磁盘。
- 好处：零注解处理器、零迁移成本、整个数据目录可直接备份/拷贝。
- 想换成 Room 时，只需要替换 `Store` 一层，UI 不用动。

### 画布坐标约定

导图节点的 `x / y / w / h` **统一用 dp 作为世界坐标**，落盘后在不同屏幕密度上尺寸一致；
手势增量和 `Canvas` 绘制用的是像素，在 `MindMapScreen` 里按 `density` 换算。

## 四、构建与运行

### Android Studio（推荐）

直接 `File → Open` 打开本目录，Gradle Sync 后运行即可。要求 JDK 17、Android SDK Platform 36、Build-Tools 36。

### 命令行

```powershell
.\build.ps1                 # 等价于 assembleDebug
.\build.ps1 assembleRelease
.\build.ps1 connectedDebugAndroidTest   # 需要连着设备/模拟器
```

产物：

- `app/build/outputs/apk/release/app-release.apk` —— 2 MB，开了 R8 压缩与资源裁剪，用 debug 签名，可直接安装
- `app/build/outputs/apk/debug/app-debug.apk` —— 54 MB，仅用于开发调试

也可以直接用 Gradle：

```powershell
gradle assembleDebug
gradle assembleRelease
```

### 关于 `build.ps1`

这台机器的环境变量 `ANDROID_SDK_HOME` 指向 `D:\AndroidAVD`，而当前开发沙箱不允许写入工程目录之外的路径
（`C:\Users\<user>\.gradle` 同样不可写）。`build.ps1` 只是把 **Gradle 用户目录**、**Android 偏好目录**、
**AVD 目录**都切换到工程内的隐藏目录 `.gradlehome/` 和 `.androidhome/`，并从机器全局位置复制一份
`debug.keystore` 用于签名。

**在 Android Studio 里正常打开工程不需要这个脚本**，这些目录也已经在 `.gitignore` 里。

已在 Pixel 6（Android 13，x86_64 模拟器）上完整验证三个模块，
包括拍照与相册取图、跨文件夹移动、导图拖动缩放与原地展开、左滑删除、全屏看图翻页、
索引树的断开 / 重新挂接父索引 / 自动排版。

其中两处用自动化测试兜底：

- **双指缩放**由 `ImageViewerZoomTest` 用 Compose 手势注入验证（`adb shell input` 不支持多点触控）；
- **自动排版算法**由 `TreeLayoutTest` 覆盖根节点不动、子节点在右侧、兄弟子树不重叠、跨树不互相干扰。
